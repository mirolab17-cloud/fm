# تحديث V10

## الخطوات (مرتبة)
1. انسخ محتوى `firestore.rules` كاملاً إلى Firebase Console ← Firestore Database ← Rules ← **Publish**.
2. ارفع كل الملفات (استبدل القديمة) على الاستضافة.
3. افتح الموقع بـ Ctrl+F5 (أو امسح الكاش) ثم ادخل بحساب المدير.
4. من «إدارة المستخدمين ← ⚙️ نظام القبول» اضبط الخيارات واضغط حفظ.

## سبب خطأ «لا توجد صلاحيات على البيانات»
صفحة الإدارة تقرأ الأجهزة بـ collectionGroup، والقواعد القديمة لم تكن تسمح بها. أُضيفت القاعدة:
`match /{path=**}/devices/{deviceId} { allow read: if isAdmin(); }`
كما أن الصفحة صارت لا تتعطل كلها إن فشلت قراءة الأجهزة.

## الجديد
- نظام القبول: تبديل «اشتراط موافقة المدير»، صفحات المنتظرين، صفحات المقبولين الافتراضية، اعتماد سريع/إعادة للانتظار لكل مستخدم، اعتماد كل المعلقين.
- إرسال رابط كلمة مرور جديدة بالبريد (رسالة رسمية من Firebase): من تسجيل الدخول، من صفحة «حسابي»، ومن لوحة المدير لأي مستخدم.
- تغيير كلمة المرور من «حسابي».
- التسجيل: الاسم الرباعي واسم الأم الرباعي في خانات منفصلة.
- صفحة `relations.html` لربط الأعضاء (أب/أم/ابن/زوج/أخ + فك الارتباط) مع تحديث الطرفين تلقائياً ومعاينة قبل التنفيذ.

## ملاحظات
- لتعريب رسالة كلمة المرور وتغيير اسم المرسل: Firebase Console ← Authentication ← Templates ← Password reset.
- لا يمكن إرسال كلمة المرور نفسها بالبريد (غير آمن، وكلمات المرور مشفّرة ولا يعرفها أحد). الرابط هو الطريقة الصحيحة.
- تقييد الصفحات للمنتظرين/المقبولين يتم في الواجهة، أما الحماية الفعلية للبيانات فبالقواعد: المنتظر لا يقرأ البيانات إلا إذا حددت له صفحة واحدة على الأقل.
